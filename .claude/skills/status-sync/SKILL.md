# Status Sync

## Когда срабатывает
Фразы вида: "занеси отклик по X", "отправил в Y", "обнови статус по Z на screening",
"по ROGII офер", "Photoroom отказали".

## Что делать

1. Найди заметку `vault/applications/{slug}.md` по названию компании (нечёткое совпадение
   по company в frontmatter, если пользователь написал название неточно).
   Если заметки нет — сообщи об этом, не создавай новую в обход vacancy-intake.

2. Обнови frontmatter заметки:
   - `status` — новое значение
   - `date_applied` — если статус меняется на `applied` и поле ещё пустое, проставь
     сегодняшнюю дату
   - `sheet_row_synced: false` — временно, пока не пройдёт шаг 3

3. Вызови `scripts/sheets_sync.py` с параметрами из frontmatter заметки:

```
python scripts/sheets_sync.py \
  --company "<company>" \
  --role "<role>" \
  --status "<status>" \
  --date-applied "<date_applied>" \
  --source "<source>" \
  --recruiter "<recruiter>" \
  --location "<location>" \
  --salary "<salary_range>" \
  --cv-file "<cv_file>"
```

   Скрипт сам ищет строку: сначала по Company + Role, затем по CV File, затем только по Company
   (если такая строка одна). Нашёл — обновляет (название компании в Sheet не меняет),
   не нашёл — добавляет новую. Если совпадений несколько, скрипт ничего не пишет и выходит
   с кодом 2 — сообщи пользователю, какие строки подошли, и спроси, какую обновлять.
   Если не уверен, какая строка найдётся, сначала запусти тот же вызов с `--dry-run`.

4. После успешного выполнения скрипта — поставь `sheet_row_synced: true` в заметке.
   Если скрипт упал с ошибкой — сообщи пользователю текст ошибки прямо, не скрывай
   и не притворяйся, что синхронизация прошла.

5. Коротко подтверди пользователю: что изменилось, в каком статусе теперь компания.
