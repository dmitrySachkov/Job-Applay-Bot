# Vacancy Intake

## Когда срабатывает
Пользователь присылает сырой текст вакансии (со скрина, с job board, пересланный текст от рекрутера)
и явно или неявно просит завести это как отклик.

## Что делать

1. Извлеки из текста вакансии:
   - company (название компании)
   - role (точное название позиции как в вакансии)
   - seniority/grade
   - stack — список технологий, раздели на must-have и nice-to-have
   - location / remote policy / relocation support (и куда именно)
   - salary_range (если указана, в оригинальной валюте)
   - source (откуда вакансия — LinkedIn, сайт компании, рекрутер и т.п., если известно)
   - recruiter (имя, если указано)
   - hard requirements, которые явно исключают кандидата, если такие есть (см. список
     дисквалификаторов ниже) — если находишь совпадение, СРАЗУ предупреди пользователя
     текстом в чате, не создавай заметку молча.

2. Дисквалификаторы (сверься, прежде чем продолжать):
   - только US/Canada remote без relocation
   - RxSwift как core-требование (а не "плюс")
   - iGaming
   - оплата в рублях
   - обязательный Objective-C

3. Сделай slug компании: lowercase, пробелы → дефисы, без спецсимволов.
   Проверь, нет ли уже `vault/applications/{slug}.md`. Если есть — не создавай новую,
   спроси пользователя, что делать (это повторный отклик или обновление).

4. Создай `vault/applications/{slug}.md` с frontmatter (формат — в корневом CLAUDE.md,
   поле `status: draft`, `date_created` — сегодняшняя дата) и телом заметки:

```markdown
## Вакансия (as-is)

<исходный текст вакансии, без изменений>

## Извлечённые требования

**Must-have:**
- ...

**Nice-to-have:**
- ...

**Стек:** ...
**Локация / relocation:** ...
**Зарплата:** ...
```

5. Сообщи пользователю кратко: компания, роль, есть ли дисквалификаторы, и что дальше —
   предложи запустить `cv-adapt`, но не запускай автоматически без подтверждения.
