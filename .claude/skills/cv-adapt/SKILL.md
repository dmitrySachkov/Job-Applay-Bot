# CV Adapt

## Предусловие
Заметка `vault/applications/{slug}.md` уже существует (создана skill'ом vacancy-intake)
и содержит секцию "Извлечённые требования". Если её нет — сначала запусти vacancy-intake.

## Что делать

1. Прочитай `templates/cv_master.docx` (используй docx skill из системы для чтения .docx).
   Это эталонное резюме — источник правды о реальном опыте. Не выдумывай факты,
   которых там нет.

2. Построчно сверь "Извлечённые требования" из заметки с содержимым резюме. Для каждого
   пункта must-have определи статус:
   - **Закрыто явно** — есть прямое соответствие в резюме
   - **Закрыто косвенно** — есть смежный опыт, можно переформулировать буллет, чтобы это
     стало видно (пример: Combine-опыт в Coral Club/AIKYNETIX закрывает "reactive programming")
   - **Отсутствует** — честно отсутствует, маскировать нельзя

3. Допиши в заметку секцию:

```markdown
## Gap-анализ

| Требование | Статус | Комментарий |
|---|---|---|
| ... | закрыто / частично / отсутствует | ... |

**Рекомендация по позиционированию:** ...
**Что честно проговорить на созвоне, если спросят:** ...
```

4. На основе gap-анализа подготовь ЧЕРНОВИК (пока не финальный файл, текст в чате или
   временный .md) адаптированного резюме:
   - Меняй порядок и формулировки буллетов под приоритеты вакансии
   - Не добавляй технологии/проекты, которых не было в cv_master.docx
   - Summary/заголовок — под конкретную роль и грейд
   - Если есть gap — не пытайся его скрыть форматированием, лучше усиль соседние
     релевантные пункты

5. Если вакансия предполагает cover letter или ответы на скрининговые вопросы формы —
   подготовь и их черновиком, тем же принципом (только факты из cv_master.docx).

6. ПЕРЕДАЙ черновик(и) на обработку skill'у `humanize` ПЕРЕД тем, как сохранять
   финальный .docx в `output/`. Не создавай финальный файл в обход humanize.

7. После humanize — создай папку вакансии `output/{Company}_{Role}/` и собери в неё (через docx skill):
   - `CV_{Company}_{Role}.docx`
   - `CoverLetter_{Company}_{Role}.docx` — если готовился cover letter
   - `FormAnswers_{Company}_{Role}.md` — если готовились ответы на форму

   Впиши путь к CV (`output/{Company}_{Role}/CV_{Company}_{Role}.docx`) в поле `cv_file`
   во frontmatter заметки. Файлы одной вакансии не кладутся в корень `output/`.
